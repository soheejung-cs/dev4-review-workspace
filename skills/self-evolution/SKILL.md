# /self-evolution <PR|CBRD-n|작업>

사용자 지시(2026-10-23 .50): 작업마다 **분석 로직·평가 지표·도메인 지식을 스스로 최적화·확장**한다. 같은 퇴보·사이드이펙트를 두 번 내지 않는 것이 목적이다.
규칙 등록부: [`references/자가진화-규칙.md`](../../references/자가진화-규칙.md). 환경 함정의 패치 대기열: `claude-workspace/하네스-패치-대기열.md`.
**하네스 자체(스킬·도구·훅·에이전트·메모리)를 바꾸는 규칙**은 [`harness/하네스-작성-규칙.md`](../../harness/하네스-작성-규칙.md) 를 따른다 — 도구(T)·서브에이전트(S)·토큰 한도(B)·문맥(C)·소스 지식 분리(K)·자가진화 방식(E), 근거는 외부 1차 자료 R-01~R-21. 4단계에서 하네스를 고치는 규칙이 나오면 그 문서의 해당 절에 근거(R-xx 또는 등록부 #NNN)와 함께 더하고, E-05(확인일 90일)를 지킨다.

## 언제
- `harness-implement` S5(자기 리뷰 뒤)·`harness-review` 8(기록)·`code-review` 보고서 끝·장애 원인 추적이 끝날 때. 리뷰 대응에서 지적을 받아 고쳤을 때도.
- 한 줄 답·상태 보고·단순 조회에는 돌리지 않는다.

## 4단계
1. **심층 분석 (라인·함수 단위)** — 바뀐 함수마다 무엇을 하는지, 하위 수준 원리를 해당되는 것만 적용한다: 메모리 접근·캐시 지역성(false sharing), 래치·뮤텍스·원자 연산·락 경합, 컨텍스트 스위칭·I/O 대기, MVCC 가시성·격리 수준, undo/redo(WAL) 영향, 그리고 정확성 축(UB·정밀도·NaN·경계). **해당 없는 축은 "해당 없음 + 이유" 로 쓰고 지어내지 않는다**(순수 값 함수에 래치 분석을 붙이지 않는다). 수치 주장은 성능규칙집 규칙 ID 와 실측으로.
2. **근본 원인 (RCA)** — 세 질문에 답한다: ① 이전 수정이 왜 원래 목표(성능 %·정확성)를 상쇄했나 ② 안정성 확보 과정에서 들어온 트레이드오프(Safety vs Performance)는 무엇인가 ③ 동시성·메모리 모델 관점에서 새로 숨어든 사이드이펙트는 무엇인가. 내 작업 과정의 실수(앵커링·검증 누락·도구 결함)도 RCA 대상이다.
3. **규칙 도출** — 다음 작업에 바로 쓸 수 있는 꼴로:
   `[자가진화 규칙 #NNN] 만약 <상황/조건> 이라면, <기존 방식 A 금지 / 최적화 방식 B 적용>`
   한 규칙 = 한 조건. 근거(PR·커밋·실측)가 없으면 만들지 않는다. 이미 등록부에 있으면 새로 만들지 말고 그 규칙에 사례를 더한다.
4. **하네스 반영** — 등록부에 append(번호는 마지막 + 1). 각 규칙에 **기계화 판정**을 단다:
   - `자동화됨` — 도구·훅·하네스 코드가 이미 막는다(커밋 해시).
   - `자동화 대기 H-NN` — 기계로 막을 수 있다 → 패치 대기열에 항목을 만들고 번호를 적는다. **LLM 이 기억해서 피하는 것을 최종 해법으로 두지 않는다**(사용자 지시 2026-10-23: 함정은 근본 원인을 하네스에서 없앤다 — 기록은 대기열 입력이고, 패치는 묶어서 한다).
   - `판단 규칙` — 기계로 못 막는 판단(설계 선택 등). 해당 스킬의 체크리스트(`code-review` §2·`harness-implement` S2)에 한 줄로 연결한다.

## 출력 구조 (이 루프를 돈 보고는 이 꼴로)
1. **[기술 분석 및 라인/함수 단위 개선안]** — 라인·함수 단위 원인과 동시성·사이드이펙트 위험, 대체 코드와 근거.
2. **[회고 및 자가진화(Self-Evolution) 리포트]**
   - **성능 저하(또는 결함) 근본 원인(RCA)**
   - **사이드이펙트 도감** — 발견된 것·잠재된 것(의도한 변화와 부수 변화를 나눈다)
   - **신규 생성된 자가진화 규칙** — 등록부에 넣은 `[자가진화 규칙 #NNN]` 원문
   - **하네스 반영 내역** — 등록부·대기열·스킬 체크리스트에 무엇을 바꿨나(커밋)

## 하지 않는 것
- 근거 없는 일반론 규칙("항상 조심한다"). 측정 없는 성능 규칙(MEAS-01).
- 같은 내용을 메모리·등록부·스킬에 세 벌로 적기 — 규칙 원문은 등록부 한 곳, 다른 곳은 번호로 가리킨다.
- 해당 없는 하위 수준 축을 채우려고 분석을 지어내기.
