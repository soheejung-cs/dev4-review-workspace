# 자가진화 규칙 등록부

`skills/self-evolution` 루프가 만든 규칙의 정본. 리뷰·구현·성능 분석·장애 추적을 시작할 때 해당 축의 규칙을 훑는다.

- 형식: `[자가진화 규칙 #NNN] 만약 <상황/조건> 이라면, <기존 방식 A 금지 / 최적화 방식 B 적용>` — 번호는 마지막 + 1, 지우지 않는다(은퇴는 `상태: 은퇴` 로).
- 각 규칙: **근거**(PR·커밋·실측) · **적용 지점**(스킬·단계) · **기계화**(`자동화됨 <커밋>` / `자동화 대기 H-NN` → `claude-workspace/하네스-패치-대기열.md` / `판단 규칙` → 연결한 체크리스트).
- 기계로 막을 수 있는 규칙은 LLM 이 기억해서 지키는 상태로 두지 않는다 — 대기열에서 묶어 하네스 패치로 은퇴시킨다(사용자 지시 2026-10-23).
