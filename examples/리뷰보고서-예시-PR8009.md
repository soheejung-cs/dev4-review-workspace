## 2. Findings

### [코드 리뷰]
1. 🟡 [테스트 제안] `query_executor.c:8213` — TC 부재. tc/pr-8009(#3572)는 초기화 커밋만, 본문에 CTP/`/run all` 근거 없음. 오답(memoize)은 단일 세션·힌트 없이 결정적으로 재현되므로 SQL TC 로 고정할 수 있고, -495 레이스는 CTP `test_mode=yes` 가 임계값을 32 로 낮춰 JIRA 재현 2 데이터로 병렬 스캔이 열린다. (MEAS-05 자동 지적과 합침)
2. 🟡 [확인 질문] `px_scan_task.cpp:525` — MERGEABLE_LIST/BUILDVALUE_OPT 워커가 initialize() 에서 연 level-0·inner 스캔을 어느 경로가 `scan_close_scan()` 하는지 팩·grep 에서 찾지 못함(XASL_SNAPSHOT 만 543-544). `qexec_clear_access_spec_list` 는 oid_list·key_vals·copy_buf 를 놓지 않고, 비커버링 index 워커는 `scan_alloc_iscan_oid_buf_list()` 를 호출한다(scan_manager.c:3604). PR 이전부터 같으나 4번 항목이 "획득한 것을 finalize 가 놓는다" 는 계약을 세우는 자리라 여기서 확정 요청. 정적만, 동적 미확인 → 질문.

4. 🟢 [확인 질문→기록] `px_scan_task.cpp:546` — BTID 무조건 복원의 안전 근거(§1 첫 행). 조치 불필요, 원하면 주석 한 줄.
